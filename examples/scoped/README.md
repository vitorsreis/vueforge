# Scoped styles

This example demonstrates a Vue `<style scoped>` block. Vue and Vite compile
the component stylesheet with a scope attribute, so the `.card` rules apply to
this component without becoming global CSS.

## Run and render

```sh
npx vueforge serve --dev

curl -X POST 'http://127.0.0.1:9901/render?format=json' \
  -H 'Content-Type: application/json' \
  -d '{"props":{"title":"Scoped card"}}'
```

The JSON response includes the rendered content and the stylesheet in `head`.
In development, the style entry includes Vite metadata so the browser can
update the stylesheet during HMR. In production, use the files generated by
`vueforge build`.

```sh
npx vueforge build
npx vueforge serve
```
